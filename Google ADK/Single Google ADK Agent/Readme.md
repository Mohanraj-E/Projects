# Personal Finance Advisor – Gemini + Google ADK

A simple, conversational **personal finance assistant** built for people in India, powered by **Google Agent Development Kit (ADK)** and **Gemini API**.

It helps users track expenses, calculate savings rate, get budget suggestions, and receive realistic financial tips — all in friendly Indian English, using ₹ (rupees).

### Features

- Parse expenses from text/CSV-like input (e.g. "Rent,32000; Food,14000")
- Calculate current savings rate (%)
- Give actionable budget suggestions (reduce non-essentials, rent check, etc.)
- Encouraging, non-judgmental tone
- Uses custom Python tools wrapped as FunctionTool
- Runs locally in console (REPL-style chat)
